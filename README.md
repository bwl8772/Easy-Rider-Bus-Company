# Easy Rider Bus Company

A Python command-line program for checking bus-stop records and summarizing bus routes.

## Requirements

- Python 3.10 or newer

## Run

The program reads a JSON array from standard input:

```bash
python "Easy Rider Bus Company/task/easyrider/easyrider.py" < input.json
```

It reports record validation errors, route stop counts, start and finish stops,
transfer stops, and valid on-demand stops.
